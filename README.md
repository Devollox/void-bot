##

Discord bot for the **Void Presence** community, built with **TypeScript** and **discord.js**.

## Features

- **Support Tickets**: Users can open private support tickets with role-based access for moderators and developers.
- **Ticket Management**: Automatic channel creation, duplicate-ticket protection, close flow, and open-ticket counter.
- **Server Statistics**: Regularly updates server statistics and keeps community data fresh.
- **Rules Acceptance**: Interactive rules flow with button-based confirmation.
- **Redis Integration**: Reliable ticket state storage across bot restarts.

## Built With

- [TypeScript](https://www.typescriptlang.org) (Language)
- [discord.js](https://discord.js.org) (Discord API)
- [Node.js](https://nodejs.org) (Runtime)
- [Redis](https://redis.io) (Ticket state and caching)
- [Docker](https://www.docker.com) (Infrastructure)

## Usage

Configure the required environment variables, invite the bot to your server, and run it with Docker or Node.js.

The bot creates a support panel where members can open a ticket. Each ticket is visible only to the user, moderators, and developers.
